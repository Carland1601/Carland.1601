Administrar productos · Carland 1601

Agrega o elimina productos aquí y copia el resultado a productos.js en GitHub. Nada se publica hasta que lo pegues allá.

Cómo publicar los cambios

  1. Sube la foto nueva a assets/productos en GitHub (Add file → Upload files).
  2. Aquí agrega o elimina productos y pulsa Copiar productos.js.
  3. En GitHub abre productos.js → lápiz ✏️ → borra todo, pega → Commit changes.
  4. En 1–2 minutos la web se actualiza.
