¿Cómo consigo la llave? (una sola vez)
  1. Entra a GitHub y abre github.com/settings/personal-access-tokens/new.
  2. Token name: admin carland. Expiration: elige 1 año.
  3. Repository access: Only select repositories y elige Carland.1601.
  4. Permissions → Repository permissions → Contents: cambia a Read and write.
  5. Pulsa Generate token, copia el código que empieza con github_pat_ y pégalo arriba.

La llave se guarda solo en este navegador. No la compartas con nadie.
